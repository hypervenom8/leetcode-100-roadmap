# LeetCode 100 — Simple bookmarkable website

No build tools, accounts, or Supabase needed. Open `index.html` using a local web server or publish the folder on GitHub Pages.

## Publish free with GitHub Pages

1. Create a new public repository on GitHub (for example `leetcode-100-roadmap`).
2. Upload `index.html`, `app.js`, `roadmap.js`, and `style.css` to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Wait for the Pages deployment to finish. GitHub will show your public URL, usually `https://YOUR_USERNAME.github.io/leetcode-100-roadmap/`.
5. Bookmark that URL. Checkboxes and progress are saved automatically in your browser's `localStorage`.

## Notes

- The original 12 accepted problems start checked. Day 1–3 new problems remain unchecked until you confirm Accepted.
- Each problem checkbox is independent; the unique accepted counter never double-counts reviews.
- Day checkboxes track your study schedule separately from accepted problems.
- Use **Export progress** regularly; import the JSON backup on another browser/device. Clearing site data, using private mode, or changing devices can otherwise lose local progress.
- This is a standalone browser-only site. ChatGPT messages do **not** automatically change website progress. That requires a connected backend and authorized integration (Option B).
- The 70-day plan is the proposed schedule discussed in chat. It does not itself guarantee exactly 100 accepted questions; progress counter shows the real unique total.
